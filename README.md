# اینستالر حرفه‌ای نرم‌افزار حسابداری سپهریار (SEPEHRYAR Professional Windows Installer)

اینستالر سازمانی، واقعی و عملیاتی ویندوز برای نرم‌افزار مالی و حسابداری **سپهریار** پیاده‌سازی شده با **Python 3.11+** و **PySide6** با تم مشکی و طلایی لوکس (Black + Premium Gold) و رابط کاربری تمام‌فارسی راست‌به‌چپ (RTL).

---

## ویژگی‌ها و قابلیت‌های پیاده‌سازی شده

1. **بررسی واقعی آمادگی سیستم (System Check):**
   - تشخیص رم فیزیکی نصب‌شده روی مادربورد با WMI و psutil (حداقل ۸ گیگابایت).
   - تشخیص نسل و هسته‌های پردازنده (حداقل Intel Core i5 نسل ۸ یا معادل آن).
   - بررسی معماری ۶۴ بیتی سیستم‌عامل و پردازنده (`x64` / `AMD64`).
   - بررسی فضای ذخیره‌سازی آزاد (حداقل ۱۰۰ گیگابایت در درایو غیر C).
   - بررسی سازگاری نسخه و بیلد ویندوز ۱۰ و ۱۱ برای SQL Server 2019.
   - عدم مسدودسازی بررسی در صورت عدم دسترسی Admin در مرحله اول.

2. **انتخاب درایو و رعایت الزامات سیستمی (Drive Selection):**
   - اسکن خودکار درایوهای فعال سیستم و محاسبه ظرفیت کل، مصرف‌شده و آزاد.
   - **ممنوعیت اکید درایو C:** نمایش درایو C به عنوان درایو ممنوعه و غیرقابل انتخاب.
   - بررسی حد نصاب ۱۰۰ گیگابایت با امکان سوییچ حالت تست توسعه.

3. **ساختار استاندارد و غیرتخریبی ریشه (Installation Root):**
   - ایجاد ساختار در `[SelectedDrive]:\SEPEHRYAR\` شامل:
     - `SEPEHRYAR.Setup\`
     - `SEPEHRYAR.Data\`
     - `SEPEHRYAR.Backup\`
     - `SEPEHRYAR.Update\`
   - عدم حذف فایل‌ها یا بک‌آپ‌های قبلی و محافظت کامل از داده‌ها.

4. **کپی واقعی و بایت‌به‌بایت فایل‌ها (File Copy):**
   - کپی کامل پوشه `setup/` با حفظ ساختار داخلی.
   - کپی کامل پکیج‌های منتخب `exe full/` شامل کلیه DLLها، گزارش‌ها، کانفیگ‌ها و فایل‌های اجرایی.
   - گزارش‌دهی دقیق بایت‌به‌بایت، نام فایل جاری، سرعت و تعداد فایل‌ها.

5. **پشتیبانی کامل از ۵ محصول سپهریار (Product Selection):**
   - 🍽 رستوران: `SEPEHRYAR.Resturan` -> `SepandResturan.exe`
   - 🧾 حسابداری: `SEPEHRYAR.Hesabdari` -> `Hesabdari.exe`
   - 🏭 صنعتی: `SEPEHRYAR.Sanati` -> `Hesabdari.exe`
   - 💻 Client: `SEPEHRYAR.Client` -> `ClientSepand.exe`
   - 🏛 مالیاتی و سامانه مودیان: `SEPEHRYAR.TaxGov` -> `SepandYar_TaxGov.exe`

6. **پایگاه داده SQL Server 2019 Enterprise:**
   - تشخیص هوشمند اینستنس `SEPEHRYAR2019`.
   - در صورت وجود اینستنس: عدم نصب مجدد، استارت سرویس و اعتبارسنجی اتصال ODBC.
   - در صورت عدم وجود: استخراج بسته RAR با پسورد، مانت ISO، نصب سایلنت با ویژگی‌های:
     - `Database Engine Services`
     - `SQL Server Replication`
     - `Data Quality Services`
   - پیکربندی احراز هویت دومنظوره (Mixed Mode) و مدیریت امن کلمه عبور.

7. **دانلود و نصب SQL Server Management Studio (SSMS):**
   - خواندن داینامیک آدرس دانلود از فایل متنی بدون هاردکد.
   - دانلود چندتکه‌ای با نمایش درصد و حجم دریافت‌شده.
   - اجرای سایلنت و اعتبارسنجی نصب.

8. **نصب و ثبت پیش‌نیازها و فونت‌ها:**
   - کریستال ریپورتز ۲۰۰۸ نسخه ۶۴ بیتی (`CRRedist2008_x64.msi`).
   - استیمول‌سافت ۲۰۱۳ (`Stimulsoft Reports.Net 2013.2.msi`).
   - ثبت استاندارد فونت‌های فارسی (ایران‌سنس، آراد) در رجیستری ویندوز و اطلاع به سیستم‌عامل.

9. **میانبرهای ویندوز (Shortcuts):**
   - ایجاد خودکار میانبرهای فارسی روی دسکتاپ و منوی استارت به صورت واقعی و بدون آدرس فیک.

10. **اعتبارسنجی نهایی ۱۲ گانه (Final Verification):**
    - بررسی سلامت کلیه مؤلفه‌ها قبل از اعلام موفقیت نهایی.

11. **لاگینگ و مدیریت خطای لحظه‌ای:**
    - ثبت دقیق لاگ در `SEPEHRYAR.Setup\install_*.log` و پنجره داخلی اینستالر.
    - امکان تلاش مجدد (Retry) در صورت بروز خطا در هر مرحله.

---

## نحوه اجرا در محیط توسعه

```bash
# نصب وابستگی‌ها
py -m pip install -r requirements.txt

# اجرای برنامه
py main.py
```

---

## نحوه بیلد و تولید فایل اجرایی EXE

```bash
py build_installer.py
```
خروجی در پوشه `dist/SEPEHRYAR_Installer/` ایجاد می‌گردد.
